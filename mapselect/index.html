Map uncertainty can fail at the places a map selects.

Machine-learning maps help choose where carbon is credited and where aid goes. Intervals that hold on average can be too narrow or needlessly wide at exactly those places. mapselect calibrates each selected place only on audited places the same rule would have selected.

1.8×wider than needed

The failure also runs the other way. At the poorest 5% of survey villages in 23 African countries, a wealth map's default intervals covered 0.98 of the true values, 1.8 times as wide as intervals calibrated on the villages the rule would also select, which still covered 0.91. Aid targeted with them screens out villages it need not.

Which audited places count?

Ask one question of each audited place: if it swapped places with a selected one, would the rule still select that slot? The places that pass are the reference set, and they are the fair comparison, because they went through the same rule.

Selected candidateOther candidateAudited, in the reference setAudited, not in it

Click any audited place to try the swap. For this rule the answer has a closed form: an audited place passes if its predicted value beats the first candidate left out. mapselect has closed forms for quotas, budgets and publication masks too, so no swap is ever rerun.

Plan the audit before visiting a single plot

Reference sets depend only on ranks, so their size follows from counts you already know. Change the numbers and the audit updates.

Audit needed

Targeting works because audited places below the rule's cutoff never enter a reference set. It suits a new audit that must come before the decision. If you can audit after selecting, measure the selected places or sample among them: this selection effect does not arise there. An existing inventory cannot be redrawn.

Coverage floor in one region

audited places, for 3,000 candidates or your population if larger

A floor is what an audit can guarantee, computed with SC-GeoCCP's penalty of 0.95. Observed coverage is often well above it, and a region can still fall short of 0.90.

Use it

Python, with numpy and scipy only. Rule, reference set, interval.

pip install .     # from the package folder; not yet on PyPI

import numpy as np
import mapselect as ms

# mu: the map; audited, candidates: a random split of one population
# y is known at the audited places only
sel = ms.top_k(mu[audited], mu[candidates], K=30)
scores = np.abs(y[audited] - mu[audited]) / sigma[audited]
q = ms.jomi(scores, sel, alpha=0.1)       # +inf if too few audited places pass
J = candidates[sel.selected]
lower, upper = mu[J] - q * sigma[J], mu[J] + q * sigma[J]

ms.plan.n_for_finite(m=3000, K=30)        # audit size, before any outcome
ms.plan.n_budget_for_finite(300, K=30)    # the same, inside the top 300 places

The guarantees need a random audit of one finite population or of a stratum fixed in advance, a separately fitted map, and a rule that uses covariates alone. Rules that read audited outcomes, audits that are not random and transfer to unsampled regions fall outside them.
